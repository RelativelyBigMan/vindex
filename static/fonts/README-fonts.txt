SD Modern Roman / SD Modern Mono
================================
These fonts are subsets of the Latin Modern fonts (lmroman10-regular,
lmroman10-italic, lmroman10-bold, lmmono10-regular) by B. Jackowski and
J. M. Nowacki (GUST e-foundry), downloaded from CTAN: https://ctan.org/pkg/lm

Changes: reduced to Latin-1 + common punctuation, converted to WOFF2,
and renamed (as the GUST Font License requests for derived works).
